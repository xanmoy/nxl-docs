# Syntax

NXL uses familiar symbols while keeping block structure explicit with `{}`.

## Blocks

```nxl
if age >= 18 {
    print("Adult")
}
```

## Comments

Single-line comments use `//`:

```nxl
// This is a comment
```

## Identifiers

Identifiers can look like:

```nxl
name
age
my_variable
```

## Delimiters

The lexer recognizes:

```text
( ) { } [ ] , . :
```

## Strings

NXL source can contain strings such as:

```nxl
"Hello"
'Tanmoy'
```

## Numbers

Examples include:

```text
123
42.5
```
