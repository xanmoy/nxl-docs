# Built-ins

## `print()`

NXL currently provides one built-in function:

```nxl
print("Hello")
```

The interpreter evaluates the argument and writes it to stdout.

Example:

```nxl
print(23)
```

Output:

```text
23
```

Additional standard-library functionality is planned for future milestones.
